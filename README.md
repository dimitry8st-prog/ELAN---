# ÉLAN — кабинет доказательной косметологии

Лендинг-сайт кабинета косметологии **ÉLAN** (Москва): услуги, специалисты, прайс, акции, блог и онлайн-запись на консультацию.

Живой превью после запуска: [http://localhost:5173/](http://localhost:5173/)

---

## О проекте

Сайт представляет бренд **ÉLAN** — кабинет доказательной косметологии с акцентом на персональный план процедур, естественный результат и прозрачные цены.

Одностраничный лендинг с якорной навигацией: посетитель знакомится с услугами и командой, смотрит прайс и акции, читает FAQ и оставляет заявку на консультацию.

## Стек технологий

- **[Next.js](https://nextjs.org/)** `16` + **React** `19` — UI и маршрутизация
- **[Vite](https://vitejs.dev/)** `8` + **[vinext](https://github.com/cloudflare/vinext)** — локальная разработка и сборка
- **[Tailwind CSS](https://tailwindcss.com/)** `4` — стили
- **TypeScript** `5.9`
- **[Drizzle ORM](https://orm.drizzle.team/)** + Cloudflare D1 — опциональная БД
- **Cloudflare Workers** (через vinext / Wrangler) — целевой рантайм деплоя

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/dimitry8st-prog/ELAN---.git
cd ELAN---
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Запустить режим разработки

**Linux / macOS / Git Bash:**

```bash
npm run dev
```

**Windows (PowerShell / CMD):** скрипт `dev` использует Unix-синтакс переменных окружения, поэтому на Windows надёжнее запускать так:

```bash
# Git Bash
export WRANGLER_LOG_PATH=.wrangler/wrangler.log && npx vite
```

```powershell
# PowerShell
$env:WRANGLER_LOG_PATH=".wrangler/wrangler.log"; npx vite
```

Откройте в браузере: **http://localhost:5173/**

## Редактирование контента

Данные лендинга (услуги, цены, специалисты) заданы прямо в `app/page.tsx` как константы:

- `services` — направления и процедуры
- `prices` — строки прайса
- `specialists` — команда врачей

Форма записи сейчас показывает подтверждение через `alert` (демо). Для продакшена её можно связать с API, Telegram-ботом или CRM.

Контакты в футере и блоке записи (телефон, email, адрес) — демо-значения; замените на реальные перед публикацией.

## Сборка для продакшена

```bash
npm run build
npm run start
```

Скрипт `build` рассчитан на Linux-окружение Sites (GNU `timeout` и др.). Для локальной проверки на Windows ориентируйтесь на `npm run dev`.

## База данных (опционально)

Проект подготовлен к Cloudflare D1 + Drizzle:

1. Опишите таблицы в `db/schema.ts`
2. Сгенерируйте миграции: `npm run db:generate`
3. Биндинг D1 объявляется в `.openai/hosting.json` и подхватывается в `vite.config.ts` для локальной разработки

По умолчанию схема пустая — сайт работает как статический лендинг без БД.

## Примечания по Windows

- Каталоги `.wrangler/`, `node_modules/`, `dist/` в Git не коммитятся
- Если `npm run dev` выдаёт ошибку вида `"WRANGLER_LOG_PATH" не является внутренней или внешней командой` — используйте запуск через Git Bash / PowerShell, как в разделе «Быстрый старт»
