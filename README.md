# ÉLAN — MVP кабинета доказательной косметологии

ÉLAN — одностраничный сайт, который помогает посетителю разобраться в услугах, увидеть ориентировочные цены и оставить заявку на консультацию.

В проекте нет вымышленных адресов, телефонов, сотрудников и временных акций. Основной сценарий простой: знакомство с подходом → выбор направления → понимание этапов консультации → отправка заявки.

## Что работает

- адаптивный первый экран и навигация;
- направления услуг с едиными ценами;
- описание этапов консультации;
- FAQ с раскрывающимися ответами;
- форма с проверкой данных, защитой от простых спам-ботов и понятными состояниями отправки;
- сохранение заявок в Cloudflare D1;
- предупреждение о противопоказаниях и пояснение об использовании данных;
- автоматическая проверка сборки, отображения страницы и API заявок.

## Быстрый старт

```bash
npm install
npm run dev
```

Локальный адрес: [http://localhost:5173/](http://localhost:5173/)

## Проверка

```bash
npm test
```

Команда собирает проект и проверяет загрузку страницы, успешное сохранение корректной заявки и отказ при неполных данных.

## Основные файлы

- `app/page.tsx` — структура, тексты и интерактивные элементы;
- `app/globals.css` — оформление и адаптивность;
- `worker/index.ts` — обработка и сохранение заявок;
- `db/schema.ts` — структура таблицы заявок;
- `drizzle/` — миграции базы данных;
- `.openai/hosting.json` — настройки публикации и D1.
